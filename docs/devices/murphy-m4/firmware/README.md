# Архив прошивок Murphy

Локальные копии заводских прошивок. Хранятся в репозитории потому, что источники ненадёжны:
`murphy.pandacat.ai` раздаёт **только текущую** версию по HTTP, и при обновлении сервера
старая пропадает безвозвратно.

⚠️ Это **чужие проприетарные бинарники**, выложенные их авторами в открытый доступ. Здесь они
лежат как исходный материал для реверс-инжиниринга и как средство восстановления устройства.

Первые три сверены с манифестами и с заметками репозитория Murphy. Проверить:

```bash
shasum -a 256 *.bin
```

## Чего здесь нет и почему

- **Дампа собственного устройства.** Появится после получения M4 — но полный дамп содержит
  раздел NVS с паролями Wi-Fi, поэтому в репозиторий он попадёт только после очистки
  `0x9000`–`0xE000`, либо не попадёт вовсе.
- **Сборок CrossPoint для M3** (релиз `murphy-m3-v1`) — они не наши и на M4 непригодны.

## Как этим пользоваться

Разбор и извлечённые константы — в [../firmware-analysis.md](../firmware-analysis.md),
скрипты — в [../tools/](../tools/). Быстрый старт:

```bash
python3 ../tools/espimg.py panda-ai-os-2.2.7.bin
```

Для восстановления устройства эти файлы напрямую **не подходят**: OTA-образ пишется не с
нулевого адреса, а с `app_offset` (у MurphyOS — `0x20000`), и стоковая ОС дополнительно
требует код активации по UID. Надёжный способ отката — собственный дамп всей флеш-памяти,
снятый до экспериментов.
